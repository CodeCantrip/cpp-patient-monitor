# C++ Patient Monitor Simulation

## Overview

A C++ project to simulate a bedside patient monitor, combining my background in respiratory therapy with my interest in software engineering and medical technology.

The goal is to develop a simulation that displays changing vital signs, evaluates alarm conditions, and eventually uses multithreading to manage different monitoring processes.

This project is also an opportunity to strengthen my understanding of C++, object-oriented programming, and concurrent programming.

## Current Features

- Simulated heart-rate reading
- SpO₂ display using a fixed value
- High heart-rate alarm detection
- Low heart-rate alarm detection
- Console-based output

## Planned Features

- [ ] Simulated changing heart-rate and SpO₂ readings
- [ ] Classes for organizing monitoring components
- [ ] Continuous monitoring with timed updates
- [ ] Multithreading
- [ ] Noninvasive blood pressure (NIBP) simulation with MAP calculation
